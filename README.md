#NumberGuessingGame
A simple console-based number guessing game implemented in Python. The computer generates a random number and the player tries to guess it with hints!

The steps are as follows:
1. The user selects a range from x to y, where x and y are integers.
2. An integer (in the range of [x,y] is randomely generated by the system.
3. The user Should guess that integer in the minimum number of guesses.
4. The minimum number of guesses can be calculated as ⌈log₂(y - x + 1)⌉ using the binary search algorithm.
